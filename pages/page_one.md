# Advantages of Open Source Software

## What is open source software?

Open source software is software that is freely available to the public. Its underlying code can be viewed and changed by anyone, which allows users and developers to adapt it to their needs and contribute to its further development.
Anyone can use it for any reason, be it students, teachers, individuals or commercial businesses. Examples for open source software include Linux, Mozilla Firefox and Audacity. But what are the advantages of it?

### What are the advantages of open source software?
Open source software offers advantages to different groups of people, although the benefits can vary depending on how the software is used. The following examples show how different advantages affect students, researchers, developers and public organisations:

- Students: Open source software makes digital tools more accessible, especially for students who may not be able to afford expensive licenses. For example, students can use LibreOffice as a free alternative to Microsoft Office to write essays, create spreadsheets, etc. It also gives students the opportunity to explore how software works and develop technical skills.
- Researchers: Open source tools support academic research by allowing researchers to access and adapt software to their specific needs. They can share tools and methods with other researchers which can make collaboration easier. A 2025 University of California survey found that 92% of researchers considered open-source software important for their work.
- Municipalities and public organisations: Governments and municipalities can save money by using open source alternatives instead of paying for expensive software licenses. For example, the Dutch municipality of Neerijnen switched to LibreOffice and saved approximately 9.000€-13.500€ annually in licensing costs.
